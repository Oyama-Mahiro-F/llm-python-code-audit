## 四、本机环境备忘

- Semgrep 不支持 Windows 原生运行，统一走官方容器（`semgrep/semgrep:latest`）；
- SWE-ReX 沙箱执行暂按预案 R2，由 shell 驱动 `docker run`；标准终端环境可验证直接接入；
- pip 走清华镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple`；
- 大模型密钥只经环境变量 `DEEPSEEK_API_KEY` 传入，**不得写入仓库任何文件**。

## 五、技术要点速记

**核心命题一句话**：不看模型怎么说，看代码跑不跑得出来。

**"可验证"的含义**（正文概念，不写在题目里）：每条被采纳的漏洞结论均附带**第三方可独立重复**的验证材料——可执行 harness、触发 payload、环境说明与完整日志，任何人可复现同一结论。

**结果三分类**：

| 类别 | 含义 | 是否计入误报 |
|---|---|---|
| 已确认（TP） | harness 跑通，payload 到达 sink 并构成漏洞 | —— |
| 已排除（FP） | 日志表明不构成漏洞或人工确认为误报 | **计入** |
| 未确认（Unconfirmed） | 环境问题或达到重试上限仍无结论 | **不计入**，占比单独报告 |

**三方对照**：纯 Semgrep ／ 纯 LLM ／ 本系统

**八项指标**：精确率、召回率、F1、误报率、动态验证确认率、未确认占比、抑制正确率、**第三方复现率**
